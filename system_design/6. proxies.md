# Proxies

Proxy server is an intermediate piece of software or hardware that sits between the client and server.

Forward proxies are used to cache data, fiter requests, log requests, or transform requests (by adding/removing headers, encrypting/decrypting or compressing a resource)

(!) A forward proxy can hide the identity of the client from the server by sending requests on behalf (от имени) of the client.

Proxies can combine the same data access requests into one request and then return the result to the user. This is called collapsed forwarding.

## Reverse Proxy

A reverse proxy retrieves resources from one or more servers on bealf of client.

Reverse proxy hides the server's identity. For example user makes a request to facebook.com -> fb proxy request one of the server and returns a response to the client.

Reverse proxy can be used for caching, load balancing or routing requests to the appropriate servers.

## Summary

A proxy is a piece of software or hardware that sits between a client and a server to facilitate traffic. A forward proxy hides the identity of the client, whereas a reverse proxy conceals the identity of the server. So, when you want to protect your clients on your internal network, you should put them behind a forward proxy; on the other hand, when you want to protect your servers, you should put them behind a reverse proxy.
