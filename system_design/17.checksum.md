# Checksum

## Background

In a distributed system, while moving data between components, it is possible that the data fetched from a node may arrive corrupted. This corruption can occur because of faults in a storage device, network, software etc.

## Solution

Calculate a checksum and store it with data.

To calculate a checksum, a cryptographic hash function like md5, sha-1, sha-256 or sha-512 is used.

The hash function takes the unput data and produces a string of fixed length; This is called the checksum.

When a system is storing some data, it computes a checksum of the data and stores the checksum with the data. When a client retrieves data, it verifies that the data it received from the server matches the checksum stored. If not, then the client can opt to retrieve that data from another replica.
