# Redudancy and replication

Redudancy is a duplication of critical components or functions of a system with the  intention of increasing the reliability.
If one primary server fails, the secondary could replace it.

Database replication is the process of copying and synchronizing data from one database to one or more additional databases.

Synchronous replication - changes made to the primary database are immediately replicated to the replica databases before the write operation is concidered complete.

Asyncronous replication - changes made on primary database are NOT immediately replicated to the replica databases.

Semi-synchronious replication - changes made to the primary database are immediately replicated to at least one replica database, while other replicas may be updated asynchronously.
